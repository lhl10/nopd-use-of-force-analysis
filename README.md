# NOPD Use-of-Force Policy Analysis

This repository contains Stata code developed for my master's capstone in Political Economy with Data Analytics at Tulane University. The project examines changes in New Orleans Police Department use-of-force following policy reforms using an intensity-based difference-in-differences research design.

The code includes data cleaning and validation, construction of outcome and control variables, creation of district-level baseline measures, fixed-effects regression analysis, robustness analyses, alternative outcomes, summary statistics, and data visualizations.

The analysis uses district and month fixed effects with standard errors clustered by police district. The primary outcome measures the severity of use-of-force incidents, with subject hospitalization and firearm discharge examined as additional outcomes.
